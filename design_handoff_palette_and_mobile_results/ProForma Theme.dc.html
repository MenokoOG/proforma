Applying it

Every screen already reads these tokens, so the whole app changes from one place. proforma-theme.css in this project is a drop-in replacement for the token block at the top of src/styles/app.css — same variable names, same three blocks (bare :root, system dark, explicit dark), so light stays outside the media query as your comment requires.

One thing it adds: --on-brand. Five rules currently hard-code color: #fff on a brand fill — the skip link, primary button, pressed chip, current step number and the switch. In dark mode the brand is a light blue, so white on it fails contrast. Swap those five to var(--on-brand).
